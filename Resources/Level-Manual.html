LEVEL

Development manual — version 0.4.0. Audio-cleanup workstation in VST3, AU (macOS), and standalone. This release does not yet include trained AI event detection or ARA integration.

1. Start

Insert Level on a vocal track. Use the LEFT module buttons to select the editing page. The adjacent ON switch enables that processing module. The upper controls include the current module's parameters and independent Input/Output gain. The input/output meters display actual signal; silence has no illuminated gain bars.

2. Audio import, waveform and spectrogram

Click IMPORT to open a WAV, AIFF or FLAC file. Drag-and-drop those file types into the window also works. JUCE AudioThumbnail builds the waveform asynchronously. An analysis worker computes an FFT spectral preview with logarithmic frequency mapping from 200 Hz to 16 kHz (limited by the input sample rate). The imported file is not overwritten.

Note: importing a file displays it for inspection and prepares offline export. It does not start DAW-synchronized playback; a transport and clip-capture engine remain to be implemented.

3. Manual time regions

Choose Lowend (plosives), Gate (pauses), Breath, Sibilance, or Mouth Noise. Drag a selection on the imported waveform to add a non-destructive orange region. Right-click a region to remove it. The present default region reduction is -6 dB with smooth approximately 15 ms fades on offline WAV output. To change its boundaries, delete and redraw; direct handle resizing, per-region gain editing and AI-assisted detection are still pending.

4. Export processed audio

After importing a recording, click EXPORT and choose 16-bit PCM, 24-bit PCM, or 32-bit floating-point WAV. Select a different filename. The audio is processed by a separate Level engine on a background worker thread; selected regions are applied as gain envelopes. Export goes to a temporary file and moves to the destination only when writing completes. The input file remains intact.

5. Modules in this development release

ModuleActual current implementation
CleanConservative attenuation of low-level samples. Not AI denoising or dereverb.
LowendBasic split between low and high content and adjustable body gain. Not adaptive voice resonance modelling.
GateThreshold-controlled gain attenuation with smoothing.
DynamicsBasic envelope-following vocal gain leveling. The target parameter is not a LUFS measurement.
BreathSoft reduction of quiet passages; not trained breath detection.
SibilanceBasic high-frequency smoothing; not an event-aware spectral de-esser.
Mouth NoiseSimple transient smoothing; not spectral click repair.

6. Presets, bypass, settings

SAVE and LOAD use .levelpreset files. RESET restores defaults. BYPASS returns the dry DAW signal. Open SETTINGS → Open Manual to reopen this file.

7. Updates and release safety

The Settings update entry is informational only. Signed release downloads, cryptographic installer verification, and automatic installation are not yet available. The macOS PKG generated by GitHub Actions is unsigned and must be validated in compatible DAWs before distribution.

8. Work remaining

ONNX inference and licensed models, accurate speech/breath/sibilance/plosive/click detection, true spectral cleanup and overlap-add, non-destructive region persistence in plugin state, ARA and transfer capture, editable spectral masks, integrated transport/zoom, full LUFS metering, plugin-side release downloads, and DAW host QA remain outside this development milestone.
