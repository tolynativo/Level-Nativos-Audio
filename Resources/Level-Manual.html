LEVEL — Nativos Audio

by Yai y Toly · Development version 0.3.0

Introduction

Level is a VST3/AU real-time vocal processor for mono and stereo audio. This early version is not an AI clip editor and does not have VoiceAssist-equivalent analysis, restoration or region editing.

Workflow

Place LEVEL on a vocal track. Click a module on the left to change its parameters. Use the corresponding ON switch to enable or disable processing. BYPASS passes the dry track without gain changes. SAVE and LOAD operate on .levelpreset files.

Modules

Clean: conservative quiet-signal attenuation. Lowend: basic low-band coloration. Gate: threshold-dependent attenuation. Dynamics: basic automatic leveling. Breath: softening of quiet audio. Sibilance: high-frequency sample smoothing. Mouth Noise: transient smoothing. These are basic algorithms, not AI event detectors.

Meters

IN and OUT are calculated from actual audio samples; with silence, the meters show no bars.

Updates

Settings shows update status. An in-plugin installer downloader requires a verified signed release manifest and has not been enabled.

Build/test notice

Unsigned Mac installers need host tests, signed releases and notarization before public distribution. The project must be validated before professional use.
